# SLR LUXURY WEDDINGS — Website

Wedding car hire website with fleet browsing, filters, price display, booking form that sends enquiries to WhatsApp, and a floating WhatsApp button.

## Folder structure
```
index.html
styles.css
script.js
README.md
images/
  hero.jpg
  about.jpg
  cars/        (car photos)
  gallery/     (1.jpg ... 8.jpg)
```

## Customise
Open `script.js` and edit the top section:
- `CONFIG` — WhatsApp number, phone, email, address, social links
- `VEHICLES` — cars, prices, descriptions, photos
- `PACKAGES`, `REVIEWS`, `FAQS`, `GALLERY`

WhatsApp number format: country code + number without `+` or leading 0 (e.g. `94771234567`).

## Run locally
Just open `index.html` in a browser.
